MCP server for Archicad

Let your AI assistant work in Archicad.

Caracara connects Claude and other MCP clients to running Archicad projects. Ask in plain language to find, inspect, change or export elements, and it drives Archicad through the Tapir add-on and the official JSON API.

Features

The whole Archicad API, shaped for agents.

Every command, without flooding the model's context or touching files it shouldn't.

351 Archicad commands

302 Tapir commands and 49 official JSON API commands, generated from their schemas and validated before anything reaches Archicad.

Query and mutate in one call

archicad_query finds elements by type, selection, classification or filter. archicad_mutate moves, rotates, edits, highlights or deletes them as one Undo step.

Element sets, not GUID dumps

Queries return a short setId and a count. The GUIDs stay on the server, and detail reads return only the fields you ask for.

Built for long operations

Slow commands hand back a job handle instead of timing out. Large listings come in pages of 100.

Safe by default

Files Archicad writes are confined to one output folder, logs leave out your model data, and HTTP transports listen only on this machine unless you allow remote access with a token.

Several Archicads at once

Discover every running instance and send each command to the one you mean by its port. Works on Windows and macOS.

Capabilities

Ask about quantities, space and the project.

Beyond finding and changing elements, Caracara answers the questions architects ask every day, and checks before it changes anything.

Exact quantities

archicad_calculate totals volumes, areas and lengths per story, type or building material with one read-only SQL query, using Archicad's own quantities. The numbers are added up exactly, not estimated by the AI.

The project at a glance

archicad_project_overview gives stories, units, layers (with which are locked or hidden), classifications and north in one call. File path, location and client details stay out unless you ask for them.

Spatial questions

archicad_spatial_query finds what is near, inside or colliding with what: conduits within 0.5 m of a wall, furniture per zone, or Archicad's own collision check. Results name elements by their Element ID.

Checked before every change

Before a change, Caracara looks for elements that were deleted since they were found, or sit on a locked layer. If there are any, or a delete would also remove doors or windows, nothing changes until you agree. Preview any change with a dry run.

Read-only mode

One switch in the extension's settings lets the AI look at your projects but never change, delete, save or export anything. Queries, calculations, overviews and dry runs keep working.

Screenshots, if you allow them

archicad_capture_view lets the AI look at the window in front or a preview of one element to check its work. It is off by default: pictures are uploaded to your AI provider, and each one uses more tokens and context.

Get started

Running in five minutes.

No Python setup: uv provisions Python and the locked dependencies itself.

Install the prerequisites

Run Archicad with the Tapir add-on installed, and install uv so it is on your PATH. Tested with Archicad 30 and Tapir 1.7.3.

Install the bundle

Download caracara-archicad.mcpb and open it with Claude Desktop, Claude Code or another client that supports MCP Bundles. For unreleased changes, use the weekly build. In the extension's settings you can switch on Read-only mode, or Allow pictures of the design (uploaded to your AI provider; they help the AI check its work but use more tokens and context).

Or configure it by hand

Add this to your client's MCP configuration (for Claude Desktop, claude_desktop_config.json):

{
  "mcpServers": {
    "ArchicadCaracara": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://github.com/parikshit99/Caracara-Archicad-MCP",
        "caracara-server"
      ]
    }
  }
}

Ask

Restart your client and try "Which Archicad projects do I have open?", then "Find every wall on the ground floor and highlight it in red." or "How much concrete is in the walls, per story?"

Heads up: the server can change the open project, export files, and send or receive Teamwork changes. Treat installing it like handing your AI client your Archicad seat, or switch on read-only mode to let it look without touching anything.

Tools

Eleven tools in front of 351 commands.

The agent reaches for the high-level tools first and drops to the low-level ones only when it needs a specific command.

discovery_list_active_archicads

Lists running Archicad instances and their ports, and flags ones that are unresponsive or missing Tapir.

archicad_query

Finds elements and reads their metadata; returns a set, element IDs, or just the fields you name.

archicad_mutate

Sets properties, moves, rotates, edits details, highlights or deletes a set of elements in one Undo step, after checking for deleted or locked elements.

archicad_calculate

Runs one read-only SQL query over a set's quantities and building materials: totals, schedules, bills of quantities.

archicad_project_overview

Stories, units, layers, classifications and north in one call; private details only on request.

archicad_spatial_query

Relates two sets in space: near, inside, or colliding (Archicad's exact check).

archicad_capture_viewopt-in

A picture of the window in front or of one element, for visual checks. Offered only when you allow pictures.

archicad_list_commandslow-level

Lists every command with a short description.

archicad_get_command_schemalow-level

Returns the argument schema of one command.

archicad_call_toollow-level

Runs any command by name after validating its arguments.

archicad_get_job

Gets the result of a long-running command, or lists recent jobs to recover a lost response.

Configuration options, HTTP transports and development setup are in the README.
